# 音藏 — 設計規範

> 改動任何介面前先讀這份。代幣寫在 `app/globals.css` 開頭，這裡說明**為什麼**。
> 2026-09-25 改為方向 B（淺色資料型）。出處：`產出/20260924_視覺提案/README.md` 方向 B 段、
> `產出/20260924_UX提案/README.md`。舊的米白／深藍墨／鐵銹紅方向已作廢，不要加回來。

## 調性

把 MusicBrainz 的表格做成有人味的版本。純白底、黑字、一個鈷藍，其餘全部黑白灰。
全站直角、零陰影；層級靠字重、1px 線與間距，不靠色塊與外框堆疊。

## 色彩與對比

| 代幣 | 值 | 對白底 | 用途 |
|---|---|---|---|
| `--bg` | `#FFFFFF` | — | 頁面底 |
| `--surface` | `#F3F5F8` | — | 表頭、hover 列、版本比較的差異列 |
| `--surface2` | `#E9EDF2` | — | 頭像底、表單裡已選的標籤 |
| `--line` | `#D7DDE5` | — | 表格線、輸入框 |
| `--text` | `#0F1420` | 18.40:1 | 正文；導覽列底線 2px |
| `--muted` | `#5A6474` | 5.98:1 | 次要文字 |
| `--accent` | `#1F4FD8` | 6.63:1 | 連結、主按鈕底、選取狀態 |
| `--accent-hover` | `#173FB0` | 8.84:1 | 主按鈕 hover |
| `--like` | `#C0205E` | 5.82:1 | 點讚，全站唯一暖色 |
| `--ok` | `#0B6E45` | 6.31:1 | 已確認 |
| `--warn` | `#855400` | 6.43:1 | 待確認 |
| `--bad` | `#B8203F` | 6.33:1 | 有爭議、表單錯誤 |

主按鈕白字壓鈷藍 6.63:1。accent 只用在連結、主要動作、選取狀態，**不做裝飾**。
只做淺色，不出深色模式：這套的價值是白紙黑字查得清楚。

**改顏色前先算對比度。門檻**：正文 ≥4.5:1；大字 ≥3:1。
**「大字」是 18pt／24px 以上，或粗體 14pt／18.66px 以上。**
WCAG 原文用 pt，換算成 px 要乘 4/3。直接把 18pt 寫成 18px 會讓門檻整個放寬（2026-09-22 修正過一次）。
`--text-lg`（18px）屬於正文等級，要 4.5:1。

## 字型（最容易被改壞的地方）

```
--font-sans: Inter → Noto Sans TC → PingFang TC → Microsoft JhengHei
--font-mono: IBM Plex Mono → SFMono-Regular → Menlo
```

- **禁用 Arial、Georgia、Times**。中文會 fallback 成醜的預設字，配色再好都廉價
- 方向 B **全站不用襯線**。介面元素一律無襯線
- IBM Plex Mono 只給目錄號、條碼、年份、數量；數字一律 `tabular-nums`，表格裡對成直線
- 字級五階：40／18／15／14／13（手機標題 28），用固定 `rem`，**不要用 `clamp()`**
- 行高 1.65，比展示型網站緊一點，因為是拿來查的
- 標題 700、按鈕與強調 600、內文 400

## 元件語彙

- **直角**：沒有任何圓角，頭像也是方的
- **炫收藏牆**：有照片才用卡片。卡片不包框，照片 1:1 裁切（`object-fit: cover`），底下三行：是什麼東西／標籤／分享者＋時間＋讚數。單則頁用 `contain` 看完整構圖
- **清單**：資料列用 1px 線分隔，不用卡片。版本比較、合作客串、合輯收錄、獎項、我有／想要、搜尋結果都是清單
- **表格**：表頭 `--surface` 底、底線 1px `--text`；列線 1px `--line`；hover 整列 `--surface`
- **多欄版本比較**：欄位在列、版本在欄；第一欄 sticky；有差異的列整列 `--surface`，不另掛「有差異」字樣；手機橫捲，每個版本欄 200px
- **標籤**：1px 外框直角；「跟誰有關」的標籤外框用 `--text` 加粗字，排在其他標籤前面
- **點讚**：愛心＋數字，`--like` 色，點過填滿；觸控區至少 44px
- **封面**：沒有真封面前是純色塊，右下角 Plex Mono 小字寫物件類型（CD／卡帶／場刊…）
- **下一階段的入口**（登入、編輯、歷史、設定）：按鈕照放，點了只顯示「下一階段」一行，不做假流程

## 介面文字

判準：**刪掉這句讀者有沒有損失**。
- 不寫解釋頁面是什麼的標題與副標（首頁沒有 H1 可見文字，導覽列下面直接是牆）
- 不寫教學提示、三步驟說明、資料模型說明、內部規則編號
- 區塊標題只用資料名：版本、主要作品、合作與客串、合輯收錄、獎項、相關收藏
- 段落沒資料就整段不出現，不放「尚無資料」；空狀態只留一句，本人多一顆按鈕

## 禁用清單

- **硬陰影**與任何陰影
- **卡片左側色條**
- **小字全大寫寬字距的 eyebrow**
- **背景網格／紙紋**
- **CSS 畫的假封面**（圓圈、斜線、唱片紋）。封面就是色塊
- **卡片外框堆疊**、側欄 infobox 把表格資料再印一次
- 麵包屑（頁首一行「藝人」連結就夠）

## 版面

- 內容寬 1200px，左右 32px（手機 18px）
- grid 一律用 `minmax(0, 1fr)`，不要裸 `1fr`，中文長句會撐開容器
- 斷點：1000px（牆三欄變兩欄、單則頁改直排、表格藏次要欄）、700px（牆單欄、導覽列搜尋收成圖示、作品封面列橫捲）
- 導覽列：音藏｜搜尋框｜炫收藏｜頭像。表單頁只剩「取消」

## 動效

150–250ms，`cubic-bezier(.22, 1, .36, 1)`。只傳達狀態，不做裝飾。
`prefers-reduced-motion` 一定要有對應。

## 圖片

上傳前壓縮。示意圖用 JPEG 品質 82、寬度 1400px 上限（約 300KB）。
**不要把 2MB 以上的 PNG 放進 `public/`。**
炫收藏表單在瀏覽器端先縮到長邊 1000px、JPEG 0.8 再存。
