## 五、實體發行.csv 說明

共 47 筆實體品項紀錄（顏社 26 筆、本色音樂 21 筆）。**判斷實體格式的方法**：優先以 Discogs（discogs.com，公開音樂發行資料庫）該張發行的 `formats` 欄位為準（CD／黑膠／DVD／藍光等皆為明確著錄的實體格式），Discogs 查無資料者，退而查該藝人維基條目discography表格是否有明確格式字樣（如「2DVD＋藍光BD」）；兩者都查無格式線索的一律**不收入**本表，改列入下方「查不到的項目」。

Discogs 上顏社（KAO!INC）與本色（本色 label id 1761823）皆有專屬廠牌頁，本次據此交叉核對每張專輯的實際發行媒介，而非僅憑維基百科discography表格「有列出＝有實體」的假設（維基表格常常CD、數位、串流不分列）。

### 值得留意的細節
- 國蛋《GDN Express》2014年版是以**USB隨身碟（M/Stick）**形式發行，非傳統CD，本表歸入「其他周邊」品項並加註說明；2024年另有黑膠再版。
- 國蛋、蛋堡多張作品後期在Discogs上出現「同一標題、不同catno」的CD／黑膠雙版本（如GDNA、Pineapple Bun），本表以「版本說明」欄註記，未重複列出完全相同版本。
- MC HotDog的《差不多先生》《貧民百萬歌星》《廢物》三張專輯，Discogs均查得「標準版CD」與「豪華限定版CD（Dlx/Ltd，部分為2xCD）」兩種獨立編目，本表各拆為兩列。
- 兄弟本色《台北小巨蛋日落黑趴》演唱會影音，維基條目discography表格明確標示「2DVD＋藍光BD」，本表拆為DVD與藍光兩列；Discogs無此條目，來源為維基百科原文。
- 顏社「顏社煮場秀」系列（2021年，國蛋／Leo王／春艷／夜貓組各出一輯）經查證國蛋版本在Discogs上為「6xFile, MP3, Album」，**確認為純數位發行**，故整個系列（含Leo王、春艷、夜貓組版本）均未收入實體發行.csv，一併列入下方「只有數位發行」清單。

## 九、可能有爭議的地方

1. **萬志軒**：條目「旗下藝人」表格中列出，但條目全文（簡介、獲獎紀錄段落）完全沒有其他提及，可能是近期才加入、資料尚不完整的藝人，其現任狀態與活動內容都僅能依表格本身判斷。
2. **PUZZLEMAN、雲端司機(CLOUDRIVER)**：在顏社discography表格出現但未列入任何藝人分類表格，關係定位模糊，本次選擇保守排除，但不排除是條目編輯遺漏、實際上應屬現任藝人。
3. **夜貓組《健康歌曲》(2024黑膠) vs.《健康歌曲OwO》(2017)**：無法百分之百確認是否為同一張專輯的不同版本／改標題再版，抑或Discogs條目命名誤差。
4. **兄弟本色現況**：2023–2024年有過短暫重組發單曲《Return to Duty》，之後未見後續動態，本次判定為「前藝人」（非持續活躍），但若2024年後仍有活動未被本次查證涵蓋，此判定可能需要更新。
5. **本色音樂並無公司官方維基條目**，本研究完全依賴individual藝人條目infobox交叉比對得出旗下名單，無法排除有本色簽約藝人但其個人維基條目未寫明「經紀公司」欄位、因而被本次研究漏收的可能性。
