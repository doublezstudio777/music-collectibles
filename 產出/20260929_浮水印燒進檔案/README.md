# 浮水印燒進照片檔（2026-09-29）

起因：直接開照片網址（例 `/img/p/FYlAwDEUxVVTES_s_t.jpg`）看到的是沒浮水印的原圖，CSS 疊加擋不住直連與另存。

正式站 Version ID `cd2071d4`（功能）→ `7ac896bf`（張數標示移到右上），遷移 `0019` 只新增 `photos.orig_key` 一欄。

## 做法

- **上傳**：瀏覽器 canvas 產三個檔。主圖（長邊 1600）、縮圖（長邊 480）燒進 `@帳號 · 樂迷藏`；另外一份沒燒的原圖（長邊 1600）。伺服器不做影像處理
- **浮水印位置**：沿用 og 預覽圖的 `drawWatermark`（右下角白字加陰影＋中間斜的淡字），字級依照片短邊等比例放大縮小；畫在照片正中央的正方形裡，因為卡片與單則頁都是正方形、置中裁切，右下角的字不會被裁掉。斜字多一圈很淡的深色描邊，CD 盤面、白底上也看得到（og 預覽圖維持原樣沒動）
- **原圖**：存 R2 的 `o/{id}`。`/img/` 的檔名規則只開放 `p/a/v/r` 四個目錄，`o/` 任何寫法都是 404；刪照片（表單刪除、編輯換照片、刪帳號勾選刪照片）時原圖一起刪
- **舊版頁面**：收藏照片上傳沒帶原圖就擋（400「網頁版本太舊，重新整理再上傳」），避免沒燒的主圖又傳進來
- **CSS 浮水印拿掉**：`Watermark` 元件、`.wm`／`.wm-center` 樣式全部移除，只剩燒進檔案的一層
- **單則頁張數標示**（「1／6」）從右下移到右上：浮水印燒在右下，原位置會蓋住
- 大頭貼、維基共享資源的藝人照片、申訴證據、意見回饋附件都不燒
- 法務頁：使用條款「照片與文字的權利」、隱私權政策「照片浮水印」改成燒進檔案＋原圖不公開保存的說法

## 舊照片補燒

`網站/scripts/reburn-watermark.py`（同一支也是改站名時的重燒腳本，用法寫在 `00_現況.md`）。

- 正式站 12 張（第 3、4、5 則＋1 張還沒掛上收藏的），失敗 0。舊主圖先複製到 `o/` 當原圖，再燒浮水印；新檔一律換新檔名 `p/{id}_{8碼}.webp`，D1 引用一起換，舊檔從 R2 刪掉
- 燒法：esbuild 當場打包 `lib/watermark-burn.ts`，在無頭瀏覽器裡跑，跟網站上傳同一份程式、同一套 Google Fonts；字型沒載到就停
- 明細：`補燒報告_正式站.json`

**舊的無浮水印網址失效**：`/img/` 本來就是先查 D1 再查快取。舊檔名在 D1 查不到＝回 404，Worker 自己的快取副本（`cf-cache-status: HIT` 那層）不會再被拿出來，不用逐一清各資料中心。實測 28 個舊網址（主圖、縮圖、預覽圖）補燒前 200／401，補燒後連打兩輪全部 404，包含使用者回報的那個網址（補燒前是 HIT）。
限制：已經看過的人，瀏覽器自己的快取還留著舊圖（一年 immutable），這層站方清不到。

## 影響舊驗收
