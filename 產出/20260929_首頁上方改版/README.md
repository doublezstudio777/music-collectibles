## 歌單會不會自動增加

不會。歌單只有後台「推薦歌曲」手動新增（或寫遷移），新藝人上站不會自動找歌。另一個方向是自動的：首頁只挑「藝人目錄看得到」的藝人的歌，藝人被隱藏或頁面不顯示時，他的歌自動不出現，重新顯示又回來，不用動歌單。
