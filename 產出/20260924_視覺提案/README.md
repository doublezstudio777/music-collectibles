# 音藏 視覺方向提案（三套）

2026-09-24，網頁設計顧問（視覺）。版面與動線由另一位顧問平行處理，這份只管色系、質感、字型節奏、元件語彙。

示意頁：`方向A.html`、`方向B.html`、`方向C.html`，各含首頁上半段＋一個人的收藏頁上半段，示範資料抄自 `網站/lib/data.ts`，封面一律純色塊＋格式縮寫。截圖在 `img/`（每套 1440 與 390 各一張，另有現況三頁對照）。三套在 1440 與 390 都量過 `scrollWidth`＝視窗寬，無橫向溢出；Google Fonts 全部實際載入（`document.fonts` 驗過），沒有掉到系統字。

對比度門檻沿用 `網站/DESIGN.md`：正文 ≥4.5:1、18pt（24px）以上 ≥3:1。下面每個數字都是用 WCAG 公式算的，不是目測。

沿用不動的規範：Inter → Noto Sans TC 的無襯線骨架、禁 Arial／Georgia／Times、介面元素一律無襯線、rem 固定字級不用 clamp、動效 150–250ms、`prefers-reduced-motion`。要換掉的是「唱片內頁／檔案館／米白／深藍墨／鐵銹紅」這一整段調性與色票。

## 現況的問題（為什麼要換）

看 `img/現況_首頁_1440.png`。米白底 `#F4F1EA` 一類的暖紙色配上鐵銹紅按鈕與深藍墨色塊，三個顏色各自有溫度，湊在一起像三個品牌。深藍卡片「把手上那件講清楚」裡塞了三步驟教學＋一段說明，這是路標句最密的地方；「需要幫忙辨識」卡的說明文也是同一類。收藏頁空狀態有 icon＋標題＋一句教學＋按鈕，四層。

三套提案的介面文字統一收斂成：導覽四個詞、一顆「炫收藏」、每則分享只有「作者 · 時間／標題／內文／標籤／點讚數・我有・想要」，側欄只有標題與資料列，沒有任何解釋句。

## 方向A 深色展示型

**調性一句話**：燈光調暗的唱片行，封面自己發光。

參考 Letterboxd 與 Musicboard 的「深底＋封面牆＋點讚愛心」，但把它們資訊密度太高的問題拿掉：留白加倍、分享用分隔線不用卡片外框、側欄才用淺一階的面板。

### 色票

| 代幣 | 值 | 對 bg | 對 surface | 對 surface2 | 用途 |
|---|---|---|---|---|---|
| bg | `#0E1014` | | | | 頁面底，冷調近黑，不用純黑 |
| surface | `#161A20` | | | | 側欄面板 |
| surface2 | `#1E232B` | | | | 標籤、頭像底 |
| line | `#2A303A` | | | | 分隔線 |
| text | `#E8EAEE` | 15.81 | 14.50 | 13.10 | 正文 |
| muted | `#9AA3B0` | 7.47 | 6.85 | 6.19 | 次要 |
| accent | `#5FE3B5` | 11.92 | 10.93 | 9.88 | 主要動作、選取 tab、已確認 |
| like | `#FF6B8B` | 7.01 | 6.43 | 5.81 | 點讚愛心與數字 |
| ok | `#5FE3B5` | 11.92 | | | 已確認 |
| warn | `#F2C14E` | 11.35 | 10.40 | 9.41 | 待確認 |
| bad | `#FF7B8E` | 7.69 | 7.05 | 6.37 | 有爭議 |

accent 當按鈕底色時文字用 `#0E1014`（11.92:1），不用白字（白對薄荷綠只有 1.3）。

### 字型

Inter → Noto Sans TC，只用無襯線。標題 700、內文 400，中間不放 500 以外的字重。字級五階：44／19／17／15／13（手機 30／16／15／14／13）。行高 1.7。不用襯線，因為深底上的襯線中文在 Windows 會斷筆，而且會把調性拉回「檔案館」。

### 封面與卡片

封面 6px 圓角、零陰影、零外框，hover 上浮 3px。分享列用 1px 分隔線，不包框。側欄面板 10px 圓角、`surface` 底、零陰影。狀態標籤用 1px 同色外框＋同色字，不填底。

### 深淺策略

深色為預設，做淺色模式只是把七個代幣反轉（bg `#F5F6F8`、text `#14171C`、accent 換 `#0F8F6A` 才過 4.5），元件不動。但建議第一階段只出深色，理由在「風險」。

### 風險

- 使用者上傳的封面照大多在白桌或白牆上拍，放在深底會變成一個個亮矩形，比純色塊示意更跳。要靠上傳時裁到方形＋固定 6px 圓角壓住。
- 深底站給人「夜間／小眾」的印象，如果之後要讓一般樂迷覺得親切，門檻比淺色高。
- Windows 上 Noto Sans TC 在深底的細筆畫會顯得比 Mac 更瘦，字重要實機看。

## 方向B 淺色高對比資料型

**調性一句話**：把 MusicBrainz 的表格做成有人味的版本。

參考 MusicBrainz 的「版本總表就是主角」與 Discogs 的黑白骨架，把它們工具冷感的部分（Verdana、洋紅色帶、緊到不能呼吸的列高）換掉。單一鈷藍是唯一的顏色，其餘全部黑白灰。

### 色票

| 代幣 | 值 | 對 bg | 對 surface | 對 surface2 | 用途 |
|---|---|---|---|---|---|
| bg | `#FFFFFF` | | | | 頁面底 |
| surface | `#F3F5F8` | | | | 表頭、側欄標題列、hover 列 |
| surface2 | `#E9EDF2` | | | | 頭像底 |
| line | `#D7DDE5` | | | | 表格線 |
| text | `#0F1420` | 18.40 | 16.85 | 15.65 | 正文 |
| muted | `#5A6474` | 5.98 | 5.48 | 5.09 | 次要 |
| accent | `#1F4FD8` | 6.63 | 6.07 | 5.64 | 連結、選取 tab、主按鈕底 |
| like | `#C0205E` | 5.82 | 5.33 | 4.95 | 點讚 |
| ok | `#0B6E45` | 6.31 | 5.77 | 5.36 | 已確認 |
| warn | `#855400` | 6.43 | 5.89 | 5.47 | 待確認 |
| bad | `#B8203F` | 6.33 | 5.80 | 5.39 | 有爭議 |

白字壓 accent 6.63:1，hover 加深到 `#173FB0`（8.84:1）。

### 字型

Inter → Noto Sans TC 做介面與正文；IBM Plex Mono 只給目錄號、條碼、數量欄，`tabular-nums` 讓數字對齊成直線。全站直角，沒有任何圓角。字級五階：40／18／15／14／13。行高 1.65，比 A 緊一點，因為它是拿來查的。

### 封面與卡片

封面是 72px 或 44px 的小方塊，出現在列的最左邊當識別，不當主角。分享是「列」不是「卡」：上下各一條 1px 線。側欄用 1px 外框＋灰底標題列的小表格。狀態標籤 1.5px 實線外框、粗體字。

### 深淺策略

只做淺色。這套的價值是「白紙黑字查得清楚」，做深色會失去定位。

### 風險

- 「炫收藏」放在這種版面裡會像在填表，展示的快感最弱。點讚愛心是全頁唯一的暖色，撐不撐得起社群感要看真實內容量。
- 表格在手機要砍欄（示意頁 700px 以下已藏格式與目錄號兩欄），版面顧問那邊要一起定手機表格規則。
- 純白底對長時間瀏覽比 A、C 都刺眼。

## 方向C 灰階＋單一強調色

**調性一句話**：美術館的展品標籤，一支螢光筆。

沒有直接對應的競品。反過來用了調研的結論：Letterboxd／Musicboard 密度太高、Discogs／MusicBrainz 太冷，中間的空位是「有人在認真整理」的溫度感，這套用襯線標題與白卡片去補，用一個檸檬綠當唯一的情緒。

### 色票

| 代幣 | 值 | 對 bg | 對 surface | 對 surface2 | 用途 |
|---|---|---|---|---|---|
| bg | `#EFEFEF` | | | | 頁面底，中性灰不偏暖不偏冷 |
| surface | `#FFFFFF` | | | | 分享卡、收藏格、標籤 |
| surface2 | `#E3E3E3` | | | | 備用 |
| line | `#CFCFCF` | | | | 分隔線、格線 |
| text | `#141414` | 16.02 | 18.42 | 14.35 | 正文、頭像底、選取標籤底 |
| muted | `#5C5C5C` | 5.82 | 6.69 | 5.21 | 次要 |
| accent | `#CFF03A` | 1.13 | | | **只當填色**：主按鈕底、點讚圓點、標題底線、tab 底線 |
| accent-text | `#3E6300` | 6.11 | 7.02 | 5.47 | 需要綠色文字時用這個 |
| ok | `#3E6300` | 6.11 | 7.02 | 5.47 | 已確認 |
| warn | `#7A5800` | 5.67 | 6.51 | 5.08 | 待確認 |
| bad | `#A3253B` | 6.33 | 7.28 | 5.67 | 有爭議 |

檸檬綠上永遠壓黑字（14.19:1），它不當文字色。這是這套唯一要守的規則。

### 字型

標題走 Instrument Serif → Noto Serif TC（西文襯線排第一，數字與英文吃到襯線質地，中文借骨架落回思源宋），字重固定 400，不用粗明體。介面與內文走 Inter → Noto Sans TC。字級：64／30／26／17／15／13，襯線與無襯線各自三階。行高 1.7。

### 封面與卡片

封面直角、零圓角，首頁用 2px 灰縫拼成一整條「膠捲」，收藏頁每格是白卡片＋封面＋兩行圖說。分享是白卡片、2px 圓角、零陰影、零外框，靠灰底襯出來。點讚是一顆檸檬綠圓點裡一個黑愛心，是全頁最亮的東西。標籤選取態黑底白字。

### 深淺策略

灰階最容易翻轉：bg `#141414`、surface `#1E1E1E`、text `#EFEFEF`、accent 不變（黑字壓檸檬綠在深底一樣成立）。可以做成自動跟隨系統。

### 風險

- 襯線大標在 Windows 沒裝 Noto Serif TC 時會先用網頁字型，載入前有一瞬間閃系統字，要 `font-display: swap` 配 preload。
- 檸檬綠只有一個，用的地方一多就變成 CTA 網站；規則是每屏最多兩處（一顆按鈕＋一個點讚或底線）。
- 灰底＋白卡片是最容易被做成「SaaS 後台」的組合，差別只在零陰影零外框與襯線標題，施工時這三件事任一個鬆掉就會掉回去。

## 推薦

**推薦 A，備案 C。不推 B。**

理由回到功能定案：這個站的入口是「炫收藏」與「點讚」，是拿來看別人東西、給自己的收藏被看見的地方，作品百科與版本比較是往下捲才會用到的第二層。競品裡做同一件事的兩家（Letterboxd、Musicboard）都選深色不是巧合，封面在深底上是主角，在白底上是附件。A 直接站在這條已驗證的路上，差異化留給「留白多一倍、不包框、標籤標跟誰有關」這些競品沒做的事。

C 是在「不想跟 Letterboxd 長太像」時的選擇，個性最強、最不像既有的任何一站，深淺翻轉也最便宜。代價是施工紀律要求最高，三個關鍵限制鬆一個就變後台。

B 的問題不在好不好看，在它把站的重心搬到查資料。多欄版本比較那一頁用 B 的語彙會做得最好，可以把 B 的表格規則（Plex Mono 目錄號、tabular-nums、1px 線、直角）當作 A 或 C 裡「資料區塊」的子系統，不必整站走 B。

決定方向後，DESIGN.md 要換的是調性段、色票表、禁用清單裡「米白本身就夠了」那句；字型與對比規則段照舊。

設計初稿，最終由音藏（用戶本人）確認。
