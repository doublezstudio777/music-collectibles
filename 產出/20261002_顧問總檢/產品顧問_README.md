## 必修

### M1 使用條款叫會員「自己刪除內容」，但網站沒有刪除收藏的功能

- **條款原文**：第 15 條「保留：炫收藏、編輯紀錄、留言…想刪除特定內容，請在申請刪帳前自己刪除。」（`app/terms/page.tsx` 第 177 行）
- **程式實況**：`app/api/shares/[n]` 只有 GET／PATCH／PUT，沒有 DELETE；全站 grep「刪除這則」「deleteShare」只找到留言的刪除。照片編輯 `setSharePhotos` 要求至少留 1 張。作者唯一能做的是改成「純分享」
- **畫面證據**：`img_產品顧問/01_作者看自己的收藏_沒有刪除.jpg`（作者看自己的 /share/13，按鈕只有「編輯」「純分享／開放出價／定價出售」「接受／拒絕」）
- **重現**：任一會員登入 → 開自己發的收藏 → 找不到刪除；API 也沒有可呼叫的刪除端點
- **影響**：隱私權政策第 114 行也寫會員可以「要求刪除」，條款又明說請自己刪。會員照條款操作做不到，只能寫信。屬於條款承諾與功能不符，開放收錄後內容會進 Google，刪不掉的時間更長
- **選項**：①補作者刪除（軟刪除＋照片 R2 刪檔＋扣容量，可沿用管理員 purge 的路徑）②條款改成「寫信到 service@lemibox.com 請我們刪除」，先對齊現況

### M2 條款第 12 條第 3 項「被處理時會通知並說明原因」，程式沒有任何通知

- **條款原文**：「你的內容或帳號被處理時，我們會通知你並說明原因。」（第 156 行）
- **程式實況**：管理員隱藏、下架、停權、檢舉達門檻自動鎖定，都只寫 `admin_log`，沒有寄信、也沒有站內通知。本機實測：乙、丙檢舉甲的收藏 #12 達門檻（門檻先調成 2），甲那邊沒有收到任何東西，只有打開那則才看得到「多人檢舉：疑似盜版」
- **背景**：`00_現況.md` 待討論段已記「條款與隱私權已承諾、程式還沒做」②，所以是已知。列必修的理由：10/02 起開放收錄、開始有外人進來，這條是現在每天都可能觸發的承諾，不像「刪帳後 3 年自動刪」要到 2029 才到期
- **選項**：①寄一封通知信（Resend 已接好，模板照驗證信）②條款先改成「我們會盡量通知」並註明目前做法，等律師一起看

### M3 停權與刪帳後，賣家的收藏照樣「開放出價」，買家可以一直出價、開對話

- **重現（本機）**：
  1. 甲發 #13「開放出價」
  2. 管理員停權甲 → 乙 `POST /api/shares/13/offers` 回 **200**，`GET /api/shares/13` 的 `sale.state` 仍是 `offer`
  3. 恢復甲，甲申請刪帳，管理員執行（`del-lwvkehfktj`）
  4. 乙再出價 NT$350 → **200**；丙 `POST /api/shares/13/threads` 開問賣家對話 → **200**；乙在原本的直接私訊 #6 傳訊息給已刪除的甲 → **200**
  5. 查庫：掛在已刪除帳號名下、狀態還是 `open` 的出價 3 筆（#2 NT$150、#4 NT$500、#6 NT$350）
- **畫面證據**：`img_產品顧問/03_賣家已刪帳仍可出價.jpg`（作者顯示「已刪除的會員」，出價、問賣家按鈕都在）
- **不一致的地方**：從個人頁「傳訊息」給停權或刪除的會員會回 404（`openDirect` 有查 status），但從收藏頁出價、問賣家、在既有對話傳訊息都沒查。同一件事三個入口兩種結果
- **影響**：買家以為在跟人交易，其實永遠不會有回覆；出價會一直掛「等回覆」。撮合平台的信任問題，數量會隨刪帳、停權累積
- **背景**：`00_現況.md` 記「刪帳時出售中收藏與出價要不要自動收掉仍待使用者決定」，停權那半沒記
- **建議做法**：①停權或刪帳時，把他的出售中收藏改純分享、待回覆的出價標撤回、各對話插一行系統訊息（沿用 `broadcast`）②`placeOffer`、`openThread`、`sendText` 補一個「對方帳號 status 必須是 active」的檢查。①是資料，②是防線，兩個都要
