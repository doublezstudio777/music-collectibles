## 一、頁面清單與網址結構

| 頁面 | 網址 | 誰能看 | 一句話責任 |
|---|---|---|---|
| 首頁 | `/` | 所有人 | 炫收藏牆。開站就是別人的收藏，沒有 hero |
| 單則炫收藏 | `/share/{流水號}` | 所有人 | 一則分享的完整照片、文字、標籤、點讚 |
| 炫收藏表單 | `/share/new` | 登入者 | 只有兩個必填：是什麼東西、跟誰有關 |
| 標籤頁 | `/tag/{標籤}` | 所有人 | 所有人帶這個標籤的炫收藏 |
| 藝人頁 | `/artist/{藝人}` | 所有人 | 簡介、主要作品、合作客串、合輯收錄、獎項、相關收藏 |
| 作品頁 | `/artist/{藝人}/{流水號}` | 所有人 | 作品正文、版本總表、多欄版本比較、相關炫收藏 |
| 作品頁編輯 | `/artist/{藝人}/{流水號}/edit` | 登入者 | 維基式編輯，送出前填一行修改說明 |
| 作品頁歷史 | `/artist/{藝人}/{流水號}/history` | 所有人 | 每次修改的時間、署名、說明、差異、還原 |
| 藝人頁編輯／歷史 | `/artist/{藝人}/edit`、`/history` | 同上 | 同作品頁（是否開放編輯見需回問 1） |
| 個人頁 | `/u/{帳號}` | 所有人 | 這個人的炫收藏牆＋簡介 |
| 我的頁 | `/me` | 本人 | 導向 `/u/{自己}`，多一顆「編輯簡介」 |
| 喜愛清單 | `/me/likes` | 本人 | 我點過讚的分享，只有自己看得到 |
| 搜尋 | `/search?q=` | 所有人 | 分三段結果：藝人、作品、炫收藏 |
| 登入 | `/login` | 訪客 | Email＋密碼或登入連結（施工時定） |
| 註冊 | `/signup` | 訪客 | Email、密碼、帳號名三欄 |
| 帳號設定 | `/me/settings` | 本人 | 改帳號名、密碼、刪帳號 |

### 網址規則

- **藝人識別碼**：本人藝名的英文名；沒有英文名用音譯。小寫、連字號。例：`/artist/mountain-radio`。
- **作品流水號**：掛在藝人底下，從 1 起算，依建檔順序。例：`/artist/mountain-radio/1` 是山線電台的《夜行採集》。流水號永不重用，作品刪除或合併後號碼作廢。
- **多位藝人的作品與合輯**：掛在發行方底下。發行方是唱片公司或主辦單位時，發行方也占一個 `/artist/{識別碼}`（例：`/artist/gma-2019/1`），頁面類型顯示為「發行單位」而不是「藝人」。參與的其他藝人在自己頁面的「合作與客串」或「合輯收錄」看到它，網址不變。
- **版本不另設頁**。版本是作品頁的一欄，網址用 `/artist/mountain-radio/1#v2` 定位，分享頁與比較表的欄標題都連到這個錨點。理由見四之「現行骨架診斷」。這條與現行骨架不同，列入需回問 2。
- **標籤**：`/tag/{標籤原文}`，標籤是使用者自由輸入的字串，URL encode 後直出，不做英文別名。藝人標籤點下去也是標籤頁（看所有人帶「山線電台」的分享），標籤頁頂部再給一顆「前往藝人頁」；藝人頁的「相關收藏」段就是同一份資料。

### 導覽列

三個項目，全站相同：

```
音藏          [搜尋框]                  [炫收藏]  [頭像 ▾]
```

- 未登入：右側是「登入」一顆文字連結，「炫收藏」按鈕照放，點了進登入頁、登入後回到表單。
- 頭像下拉：我的頁、喜愛清單、設定、登出。四項，不多。
- 拿掉現行的「發現／作品／我的收藏」三分頁。「作品」索引併進搜尋（搜尋框空白時 Enter 就列全部作品），「我的收藏」改成頭像。

## 二、每頁的資訊層級

寫法：第一層是不捲就看到的；第二層往下捲；「折進去」是預設收合或另開頁。

### 首頁 `/`

1. 炫收藏牆，三欄（手機一欄）。每張卡：照片、一行「是什麼東西」、標籤列（跟誰有關排最前）、分享者＋時間、愛心與數字。**沒有標題、沒有副標、沒有說明文字**，導覽列下面直接是第一排卡。
2. 捲到底自動載入下一頁。
3. 折進去：排序（最新／最多讚）放在牆右上角一個下拉，預設最新。

### 單則炫收藏 `/share/{n}`

1. 照片（可多張，橫向滑）、「是什麼東西」當標題、分享者、時間、愛心。
2. 使用者寫的文字（選填，可以整段沒有）。標籤列。連到的作品或版本（有連才顯示）。
3. 折進去：同一位分享者的其他分享四張，帶同標籤的分享四張。

### 炫收藏表單 `/share/new`

1. 照片上傳格。
2. 「這是什麼東西」單行輸入（必填）。「跟誰有關」標籤輸入（必填，至少一個，輸入時帶出既有藝人建議，選了既有藝人就連到藝人頁，自由輸入就當標籤）。
3. 「想說的話」多行輸入（選填）。「其他標籤」（選填）。
4. 一顆「發布」。
5. 折進去：「連到作品或版本」是發布後在分享頁上的一個連結「補上版本」，不放在表單裡。表單的工作是兩個必填欄位，補版本是之後的事（動線②）。

### 標籤頁 `/tag/{標籤}`

1. 標籤名當標題、幾則分享。標籤對應到既有藝人時，標題旁一顆「藝人頁」連結。
2. 炫收藏牆，同首頁卡片。

### 藝人頁 `/artist/{藝人}`

1. 名字、一行定位（例：台中三人樂團，2014 至今）、主要作品的封面列（正方形，橫向一排最多六張，多了顯示「全部 N 張」）。
2. 簡介正文（維基式，右上一顆「編輯」與「歷史」）。
3. 合作與客串（清單，每列：作品、對方、角色、哪一首）。合輯收錄（清單）。獎項（表格：年、獎項、類別、結果）。
4. 相關收藏：帶這位藝人標籤的炫收藏，四張卡＋「全部 N 則」連到標籤頁。
5. 折進去：合作客串、合輯收錄超過五列時收合成「全部 N 筆」。段落沒資料就整段不出現，不放「尚無資料」。

### 作品頁 `/artist/{藝人}/{n}`

1. 封面（正方形）、作品名、藝人、年份、類型、幾個版本。右側「編輯」「歷史」。
2. 版本比較表：**這是作品頁的主體**。第一欄是欄位名，之後每個版本一欄，欄標題是版本名，欄標題底下一排「我有／想要」與人數。有差異的列整列淺底，不另外掛「有差異」標籤。辨識特徵是表格第一列（因為找版本的人第一個要看的就是這個）。
3. 作品正文（維基式）。
4. 相關炫收藏：連到這張作品任一版本的分享。
5. 折進去：版本超過四個時，表格橫向捲動，第一欄固定；桌機也一樣，不折行。

### 個人頁 `/u/{帳號}`

1. 頭像、帳號名、一行簡介、幾則分享、幾個讚。本人多一顆「編輯簡介」。
2. 炫收藏牆。
3. 折進去：喜愛清單不在這頁，是 `/me/likes`，只有本人。

### 喜愛清單 `/me/likes`

1. 標題「喜愛清單」、幾則。
2. 炫收藏牆，卡片右上多一顆可以取消讚的愛心。
3. 原分享已刪除的，卡片顯示灰底「這則已被移除」，不留照片。

### 編輯頁與歷史頁

- 編輯：左邊編輯區（純文字或簡單 Markdown），右邊即時預覽（手機上下堆）。底部一行「修改說明」（必填，一句話）＋「送出」。未登入進不來。
- 歷史：清單，每列：時間、署名、修改說明、「看差異」「還原到這版」。差異用逐行紅綠比對，同一頁展開。

### 登入／註冊

- 登入：Email、密碼、「登入」，底下一行「還沒有帳號？註冊」。
- 註冊：Email、密碼、帳號名（就是 `/u/{帳號}` 的字串）、「註冊」。送出後寄驗證信，畫面只留一句「驗證信已寄到 xxx@xxx」。

## 三、四條核心動線

### ① 新訪客看別人的收藏 → 點讚 → 註冊

1. 打開 `/`，導覽列下面直接是炫收藏牆，第一屏至少看到六張照片（1440）或一張半（390）。
2. 點卡片進 `/share/{n}`，看完整照片與文字。
3. 按愛心。未登入 → 彈出小面板：「登入後才能點讚」＋ Email／密碼／「登入」＋「註冊」連結。**不跳頁**，登入成功後面板關掉、愛心亮起、留在原頁。
4. 點「註冊」→ `/signup?next=/share/{n}`，三欄，送出，驗證信，點信裡的連結回到 `next` 頁，愛心已亮。
5. 之後頭像下拉「喜愛清單」就有這一則。

### ② 炫收藏（只填是什麼＋跟誰有關）→ 之後補版本

1. 任何頁點導覽列「炫收藏」→ `/share/new`（未登入先登入，登入後回來）。
2. 上傳照片、填「這是什麼東西」（例：夜行採集 台灣首批 CD）、「跟誰有關」打「山線」出現既有藝人「山線電台」，選它。
3. 按「發布」→ 直接落在 `/share/{n}` 自己的分享頁。
4. 分享頁的作品連結區顯示一行「補上作品或版本」。點了出現搜尋框，選到 `夜行採集 › 首批紙套版` 就連上，分享頁出現作品封面小卡，作品頁的「相關炫收藏」也開始出現這則。
5. 沒有補也不影響任何事，那一行留著，只有本人看得到。

### ③ 從標籤走到藝人頁，再到作品與版本比較

1. 在任何炫收藏卡上點標籤「山線電台」→ `/tag/山線電台`，看所有人帶這個標籤的分享。
2. 標籤頁標題旁「藝人頁 →」→ `/artist/mountain-radio`，第一屏是名字、定位、作品封面列。
3. 點封面《夜行採集》→ `/artist/mountain-radio/1`，第一屏是封面＋資訊列，往下第一個區塊就是版本比較表，兩個版本並排，有差異的列整列淺底。
4. 在欄標題底下按「我有」（未登入照動線①的小面板）。

### ④ 編輯作品頁並留署名

1. 作品頁右上「編輯」→ `/artist/mountain-radio/1/edit`（未登入先登入）。
2. 左邊改正文，右邊預覽。底部「修改說明」填一句（例：補 2020 日版發行資訊）。「送出」。
3. 回到作品頁，正文更新，正文底下一行「最後修改：阿澤，2026-09-24 · 歷史」。
4. 任何人點「歷史」→ `/artist/mountain-radio/1/history`，看到每筆：時間、署名、說明；點「看差異」展開紅綠比對；本人或任何登入者可「還原到這版」，還原本身也會成為一筆歷史並署名。

## 四、現行骨架逐頁診斷

截圖在 `img/現況/`。用戶原話「路標語跟提示詞也太多」。判準統一用「刪掉這句讀者有沒有損失」。

### 整站

- 導覽列「發現／作品／我的收藏」三分頁砍成上面的三項。「作品」是資料庫入口，不該與「炫收藏牆」平起平坐；「我的收藏」語意跟「炫收藏」打架。
- 每頁一個大標題 H1＋一句灰字副標（`.heading-note`）的模式全砍。首頁的 H1「看看別人收了什麼」是在跟讀者解釋這頁是什麼，牆本身就在說。
- 每張卡三顆動作「儲存／我也有／加入想要」砍成一顆愛心。「儲存」已被點讚取代；「我也有」與「想要」是版本層的動作，放在作品頁的版本欄標題底下，不放在別人的分享上。
- 側欄 infobox（作品頁、版本頁、藝人頁右側那張卡）整個砍。它把同一批資料再印一次（作品頁的「已收錄版本 2／格式 CD」在表格已經有；版本頁的 12 個欄位跟比較表完全重複），標題還跟 H1 重複。
- 麵包屑砍。三層以內的結構用頁首「藝人 › 作品」一行連結就夠，而且現行麵包屑把藝人頁放在「作品 >」底下，層級是錯的。

## 五、導覽列、卡片與清單、封面比例、手機版

### 卡片 vs 清單的使用時機

- **卡片**：有照片才用。炫收藏（照片是主角）、作品封面列。卡片上文字最多三行：一行是什麼、一行標籤、一行分享者。
- **清單**：資料列。版本比較、合作客串、合輯收錄、獎項、編輯歷史、搜尋結果的藝人與作品段。清單不放縮圖，除了作品搜尋結果可放 40px 封面。
- 不用卡片的地方：藝人簡介、作品正文、表單。這些直接坐在頁面底色上。
- 禁：卡片左側色條、eyebrow 全大寫小字、硬陰影。卡片邊界用 1px 線或底色差，不用陰影。

### 封面圖比例

- 作品與版本封面：**1:1**，業界共識（Discogs、Bandcamp、Musicboard 全是正方形）。
- 炫收藏照片：**格線裡 1:1 裁切（`object-fit:cover; object-position:center`）**，單則頁顯示原比例。收藏品是實物（場刊、海報、簽名照）長寬不一，牆上不裁會變成瀑布流，瀑布流在三欄以上讀不出順序；1:1 讓牆有格線，代價是牆上看不到完整構圖，點進去才看到。
- 頭像：圓形 40px，牆上 24px。

### 手機版（390）怎麼收

- 導覽列：`音藏  [搜尋圖示]  [炫收藏]  [頭像]`，搜尋框收成圖示，點了在導覽列下方展開一行。
- 炫收藏牆：一欄，照片滿寬。
- 藝人頁作品封面列：橫向捲動，每張 120px。
- 版本比較表：橫向捲動，第一欄（欄位名）`position:sticky; left:0`，每個版本欄固定 200px。表格上方不加「左右滑動查看」提示，欄位被切一半本身就是提示。
- 編輯頁：編輯區在上、預覽在下，中間一顆「預覽」切換而不是同時顯示。
- 頭像下拉：改全寬面板。
- 觸控目標一律 44px 以上，愛心在牆上是 44px 的點擊區、圖示 20px。

## 六、需回問用戶

1. **藝人簡介是否也開放任何人編輯**。定案寫的是「作品頁面」，藝人頁的簡介與定位句是不是同一套維基式編輯、同樣留署名？線框先照「是」畫，因為兩者用同一套元件成本最低。
2. **版本不另設頁**。現行骨架有 `/work/x/version` 獨立頁，砍掉說明文字後它剩下的內容跟作品頁比較表完全一樣，所以本稿改成作品頁的錨點 `#v2`。但這會影響「分享掛在版本上」的網址與之後的 SEO；要確認可以接受。
3. **「我有／想要」在個人頁怎麼呈現**。定案講了炫收藏與喜愛清單，沒講「我有」與「想要」清單放哪。本稿在個人頁加一個「我有的版本」區塊（公開）與「想要」（只有本人看）。這兩個是不是公開、要不要保留，請定。
4. **多位藝人共同署名（不是合輯）掛誰**。定案說「看發行的是誰」；兩位藝人共同署名、由其中一人自家廠牌發行的情況，掛在那位藝人底下，另一位只在「合作與客串」看到。這樣另一位的主要作品會少一張，確認可以接受。
5. **標籤與藝人名撞名**。使用者自由輸入「山線電台」當標籤，跟既有藝人「山線電台」同字。本稿處理是輸入時帶出建議、選了就連藝人，沒選就是純字串標籤；兩者在標籤頁 `/tag/山線電台` 合流顯示。要不要合流，還是分開？
6. **點讚數要不要公開**。Letterboxd 公開讚數，而點讚在音藏是「留著以後看」的私人動作。線框上牆卡有數字，若要私密就拿掉數字只留愛心。

## 版本比較表對照競品

MusicBrainz 是唯一有版本總表的站，做法是一列一版本的橫表（欄：格式、曲目數、國家日期、廠牌、目錄號、條碼）。本稿轉置成一欄一版本：欄位在列、版本在欄，理由是比較是「同一個欄位橫著看」，版本數（2 到 6）遠少於欄位數（10 以上），轉置後桌機不用橫捲、手機橫捲的是少的那一軸。
