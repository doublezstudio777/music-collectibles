## 做了什麼

**炫收藏表單（`components/share-form.tsx` 整支重寫）**
- 單頁：照片 →「這是什麼」（前兩題必答）→「想多說一點」（都可以不填）。題目是問句：誰的東西？是什麼？哪一張專輯？周邊是「這條毛巾是哪裡出的？」（量詞跟品項走）
- 誰的東西：搜尋框最上面，下面「最近常發的」10 位；打字後結果最多 5 列，最後一列「找不到？新增『你打的字』」。性別／地區篩選、「更多」、灰字提示都拿掉
- 答完收成「值＋改」黑框；第三題在前兩題答完前淡化。換題目時下游只在對不上才清（CD 換黑膠專輯保留；換藝人後舊專輯不屬於新藝人才清）
- 專輯清單：年份／名稱／類型，先列最新 6 張＋「還有 N 張」，上方過濾框；最後「找不到？新增專輯」「不確定，先跳過」
- 周邊三組：演唱會、專輯的周邊、藝人自己出的（含「周邊與其他」），各組沒資料會寫「國蛋還沒有演唱會資料」；新增列有演唱會、專輯兩種
- 版本題預設收成「不確定　這張有 N 個版本：…　［選版本］」；版本新增維持會員待審（只有藝人、系列改事後審）
- 錯誤訊息改成依目前答案即時算：按過一次發布才顯示，答好的那一刻就消失（修掉「至少要選擇一個」）；按發布自動捲到第一個錯的題目
- 發布列：手機黏底（含 `safe-area-inset-bottom`），桌機右欄 300px 預覽卡（封面、即時標題、藝人標籤、還差什麼、發布）。同一個節點用 CSS 換位置
- 標題：「想多說一點」裡有一格「標題」，點「改」可以自己寫；寫了就出現「還原成自動標題『…』」。自訂標題存 `shares.custom_what`，系統重組標題只動 `what`，不會蓋掉自訂的
- 例子只放在要打字的格子，一格一個；規則說明與「送出審核」字樣全部拿掉

**新增藝人、系列改事後審（`lib/server/additions.ts`、`/api/catalog/rename`、`/admin/additions`）**
- 介面不問網址識別碼：名稱有英文字母就轉小寫連字號，否則 `a-` 加 4 碼亂數；撞號自動換
- 新增只問名稱；系列另有年份，可勾「不記得年份」；新增專輯一律先當專輯（不問類型）
- 新增後 `approved`、立刻選好、立刻出現在標題、發文當下就能用；同名（含別名）已在站上就直接用那位，不重複建
- 自己新增的永遠可以改名（按鈕寫「改名」，框裡另有「換成別的」），每次改寫一筆 `catalog_addition_edits`。藝人改名時，含舊名的收藏「跟誰有關」一起換；系列改名時，掛那個系列的收藏標題重組
- 後台新分頁「待確認的新增」：待確認／已確認兩區，每筆可「沒問題」「修名」「合併到既有的」，列出幾則收藏在用與改名紀錄。藝人合併沿用既有的藝人合併；系列合併把收藏逐則改掛（品項照類型找或建、版本改不確定），新增的系列軟刪除，寫操作紀錄
- 會員每天 20 筆的新增上限照舊（事後審的也算）

**單則頁（`components/share-detail.tsx`）**
- 「編輯」「編輯照片」合併成一顆「編輯」；編輯頁就是同一張表單，照片可補、刪、換封面、調順序（有變才存，封面換了重畫分享預覽圖）
- 發文者操作盒照 `#s9`：手機在照片下方、桌機右欄最上面。左邊「你的收藏」＋狀態（純分享／開放出價・N 筆出價／定價出售 NT$…・N 筆出價／已售出・成交給…），右邊「編輯」。純分享只露「我想賣」，出售中直接展開三段切換＋價格＋「改價格」，已售出是「改回出售中」。沒有做「⋯」選單
- 沒掛系列時，原本的「補上系列或品項」按鈕改成文字連結「補上是哪一張」，連到編輯頁並直接打開那一題

**登入者單則頁預設高清**
- 伺服器輸出與 hydration 第一次一律是 480 縮圖（整頁快取的 HTML 不變）；瀏覽器確認登入（`/api/me`）後才換成 1600 大圖，縮圖先墊在底下不會空白一下；大圖載入失敗（429 到上限、401）退回縮圖
- 收藏牆（首頁、藝人頁、系列頁等）沒動，仍是縮圖
- 每帳號每日大圖上限預設 300 → 1,000（`lib/server/quota.ts`）。正式站 settings 沒有覆寫值，所以直接生效
- 未登入規則不變

**第 9 項：收藏卡片固定版型（全站所有牆）**
- 同列等高；標題固定保留兩行高度（一行時下面留白，超過兩行照舊「…」）；標籤最多一行；發佈人列 `margin-top: auto` 貼底。手機原本就隱藏標籤，照舊

## 判斷項（使用者可以改）

1. 「誰的東西」仍可選多位（合作作品），選一位就收起；要加第二位按「改」再搜
2. 新增藝人撞到同名（含別名）的既有藝人，直接用既有那位，不另建
3. 周邊新增只有演唱會、專輯兩種（照線框）；藝人自有品牌的東西先用「周邊與其他」
4. 系列合併後，舊系列的「我有／想要」、成交價紀錄沒有跟著搬（新增的系列剛建，通常還沒有）；藝人合併沿用既有流程，會全部搬
5. 自訂標題上限 80 字；跟自動標題一樣時不存
6. 舊制（事前審）還掛在「待審核新增」的藝人、系列，留在原本的審核與下架頁，不自動轉
