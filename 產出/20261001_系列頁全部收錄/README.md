## 介紹句的句型

三句，依資料有無決定寫哪幾句；同一種情況再用系列鍵算雜湊挑寫法（同一頁每次一樣）。樣板字一律不留空白（全站規則），只有英數接英數時補空白（「Hyukoh 2017年」）；藝人名、版本名、唱片公司照資料原樣。沒有破折號（專輯名本身帶的除外，例如陳嫺靜那張）。

**第一句：誰、哪一年、什麼、幾首**

| 情況 | 寫法（擇一） |
|---|---|
| 專輯／單曲，有年份 | 《T》是 A Y年發行的專輯；A 在 Y年推出專輯《T》；《T》是 A 的專輯，Y年發行 |
| 有完整發行日（同年） | 另加：A 的專輯《T》在 Y年M月發行；《T》是 A 在 Y年M月推出的專輯 |
| EP | 《T》是 A Y年的EP（不加「發行的」），其餘同上 |
| 沒有年份 | 《T》是 A 的專輯，發行年份還沒有人補上；A 的專輯《T》，目前查不到發行年份；《T》是 A 的專輯，還缺發行年份的資料 |
| 曲目（專輯／EP） | 共N首歌；收錄N首歌；一共N首；全輯（EP 是全張）N首歌 |
| 曲目多碟 | 分成兩張碟，共N首歌；兩張碟一共N首 |
| 曲目（單曲） | 1 首：只有一首歌、就收這一首歌；多首：收錄N首歌、裡面有N首歌 |
| 巡迴、自有品牌、周邊與其他 | 各一組短句，不寫曲目 |

**第二句：版本**

| 情況 | 寫法 |
|---|---|
| 沒有版本 | 版本資料還沒有人補上；目前還沒有人登記版本 |
| 一個版本 | 樂迷藏目前只登記一個版本，是Y年台灣首版 CD，由X發行；站上目前只有一個版本，…；目前收錄的版本是… |
| 多個版本 | 開頭（樂迷藏收錄N個版本／站上整理了N個版本／目前登記的版本有N個）＋最多兩個細節：地區（在台灣和香港都有發行／發行地區包括…；只有一區：都是香港發行／全是香港版）、格式（CD和黑膠都有／格式有…）、年份跨度（從Y1年一路出到Y2年／最早Y1年，最新一版是Y2年）、唱片公司（唱片公司是X／經手的唱片公司有…） |

**第三句：人**（都是 0 就整句不寫）：目前／到現在／樂迷藏裡有N人登記擁有、N人想要，也有N則炫收藏可以看；只有炫收藏時：已經有N則樂迷的炫收藏／站上有N則樂迷分享的實體照片／樂迷分享的炫收藏有N則。第二、三句開頭撞同一個詞會自動換寫法。

**description**：同一套事實的短版（版本句改「樂迷藏整理N個版本（地區；格式）」或「版本是…，X發行」，人數句加「N件出售中」），一句一句放，放不下就整句不放（不從句子中間截），還有空間才接 30 字以上的系列介紹（匯入時自動寫的「CD・2009・某某唱片」這種太短的不接）。上限 80 個全形字寬。

說明：「人想要」是系列頁原本就有的「想要」（版本上的我有／想要），站上叫「願望清單」的是按讚的收藏清單，兩者不同；介紹句寫的是「想要」。
