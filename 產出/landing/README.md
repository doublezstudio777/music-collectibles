# 測試站檔案

上傳到子網域根目錄即可（建議 `dev.` 或 `demo.` 開頭，一看就知道是暫時的）。

| 檔案 | 用途 |
|---|---|
| `index.html` | 佔位頁，已內建 `noindex` |
| `robots.txt` | 全站禁止索引 |

## 上傳後一定要做

cPanel → **Directory Privacy** → 對這個目錄設帳號密碼。

理由：`noindex` 和 `robots.txt` 只擋守規矩的爬蟲，擋不住路人、擋不住不守規矩的爬蟲，
也擋不住有人把網址轉貼出去。測試階段的半成品被看到、被截圖、被討論，
之後正式上線要花更多力氣澄清。

**密碼設好後記到 `_私人/`，不要寫進這個 repo。**

## 之後轉正式網域

這批檔案是拋棄式的。正式網域上線時重做，不要沿用——
包括 `noindex` 和 `robots.txt` 記得拿掉，這是最常見的上線事故。
