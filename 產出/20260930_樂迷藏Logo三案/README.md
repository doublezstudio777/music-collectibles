# 樂迷藏 Logo 三案

日期：2026-09-30。狀態：提案，尚未選定，沒有替換網站現有圖示或字標。

品牌定位：樂迷看別人的實體收藏、分享自己的唱片／場刊／周邊，逐步累積藝人和版本資料。「樂迷藏」可讀出「樂迷」與「迷藏」，使用者已決定沿用此名。

三款都採用網站現行的白、黑、橘、直角、零陰影語言。字標以網站設計規範的 Noto Sans TC 優先；橘色 `#FF6A00` 只在圖形內作小面積標記，文字為黑色 `#111111`。未使用唱片圓盤或播放鍵，避免把收藏範圍誤限於可播放的音訊。

| 編號 | 主題 | 設計意義 | 留意 |
|---|---|---|---|
| 01 | 露一角 | 收藏盒裡有一件正被看見的物件；分享與發現 | 圖形略像檔案盒，搭配字標才明確是音樂收藏 |
| 02 | 尋一物 | 迷藏的路徑與發現的目標 | 小尺寸時路徑可能擠，若選此案須再做 16px 專用圖示 |
| 03 | 收藏格 | 物件編目，橘色標記一件值得看見的收藏 | 偏資料庫，情感和樂迷互動感較弱 |

**初步推薦 01**：一眼看懂「把收藏拿出來給人看」，也適合日後延伸成收藏卡片或貼紙。三款均為透明背景、可編輯的 800×320 SVG；同名 PNG 是 800×320 白底預覽。Logo 最終選案後，仍應測試 16／32／64px 圖示、黑白印刷、手機導覽列實際尺寸，並查商標近似。

現行網站 `網站/public/favicon.svg` 仍是以前的深藍與鐵銹紅圓盤，與已核定的黑白橘設計不同。待使用者選案後，再按 `網站/DESIGN.md` 更換；本輪沒有動正式介面。
