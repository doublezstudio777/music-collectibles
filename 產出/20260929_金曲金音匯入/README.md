## B. 首頁歌曲卡

1. **每天一首**（`components/home-pick.tsx`）：第一眼那首用台灣日期（UTC+8 的 YYYY-MM-DD）當種子，FNV-1a 雜湊＋mulberry32 固定亂數，照原本「先挑藝人、再挑那位的一首」從啟用歌單挑。歌單順序由伺服器固定輸出（`sort, id`），所以同一天所有人第一眼相同、隔天換，不需要伺服器參與，首頁仍是同一份整頁快取（驗收 2a 第二次 `x-yz-cache: HIT`）。「換一首」照舊用 `Math.random`
2. **收藏數 0 的按鈕**：歌單每首多帶 `count`（`app/page.tsx`，原本就算好的「N 則收藏」那個數），0 → 「看{藝人}的藝人頁」，>0 → 維持「看其他人{藝人}的相關收藏」，兩者都連藝人頁
3. 歌單沒有自動加歌
