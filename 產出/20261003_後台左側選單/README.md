## 條款更新公告「按完一次，下一次進來又有」

判斷的實際原因（最可能到最不可能）：
1. 1.1 在 10/01 公告、10/02 換成 1.2，舊程式的 key 是 `lmb_terms_notice_1.2`，關過 1.1 的人會再看到一次。這段時間剛好對得上
2. iPhone 上 Safari、無痕、LINE／FB 內建瀏覽器、主畫面捷徑的 localStorage 各自一份，從 LINE 點進來每次都是新的
3. Safari 對網頁腳本寫的儲存有 7 天沒互動就清的機制

修法：關閉狀態存三層，任一層有就不顯示
- localStorage（原本的）
- 第一方 cookie `lmb_tn=1.2`：`POST /api/notice` 由伺服器發（Path=/、一年、SameSite=Lax、Secure），前端同時先寫一份
- 登入會員存伺服器 `user_notices`；同意過的條款版本 ≥ 公告版本（註冊時同意 1.2）直接不顯示
- 只比「最新一版」：存的是版本號、用 ≥ 比，關過 1.2 不會再看到 1.1
- 沒放 users 表：users 有 cv_users 觸發器，任何更新都讓全站整頁快取失效

LINE 內建瀏覽器如果每次都是全新的、又沒登入，三層都存不住，這種情況仍會再出現一次；登入後就以帳號為準。
