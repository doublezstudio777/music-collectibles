## 2. 表單加上「哪個版本？」

- 選好專輯或演唱會，同一組裡直接出現「哪個版本？ 選填」，選項整個攤開，不用再點：既有版本、「不確定」、「新增版本」。選了之後收成「值　修改」一列
- 版本用口語名稱：年份＋地區＋版本名＋品項，已經寫在名稱裡的不重複（例：「2016 台灣 一般版 CD」「日版 CD」）
- 新增版本：版本名稱（例：日版、首批限定、再版、簽名版），年份、地區都選填。跟新增專輯一樣**立即可用、事後審**：送出當下就選好、帶進標題；進後台「待確認的新增」（沒問題／修改名稱／合併到同品項的另一個版本）；新增者隨時可以改名，每次都留紀錄。同一張已經有同名版本就直接用那個，改名撞名會擋下並提示「這張已經有「一般版」了，直接選它就好」
- 系列裡還沒有這種品項（例：My jinji 還沒有 CD）也能直接新增版本，品項自動建
- 標題：「系列・版本 品項」，例「My jinji・日版 CD」；版本名稱已含品項就不再加（「2016 CD」不會變「2016 CD CD」）；沒選版本維持「My jinji・CD」
- 編輯既有收藏可以用同一個欄位換版本、替自己新增的版本改名。改名只重組掛這個版本的收藏標題，同系列其他人的收藏不動
- 拿掉原本的「哪一個 CD？」題：同系列有兩個同類品項時，版本清單會把兩個品項的版本一起列出來，選版本就等於選了品項

## 判斷項（請使用者看）

1. **會員新增的版本當下就算「新增 +15 分」**：跟事後審的藝人、系列同一套規則（每天最多新增 20 筆）。要改成確認後才給分，只要改計分那一支
2. **標題格式全站改成「系列・版本 品項」**：舊的是「系列・品項・版本」（例「驗收專輯・CD・首版」）。已經存進資料庫的標題不會自己變，下次編輯、改名時才重組；第 4 則沒選版本，標題「My jinji・CD」不受影響
3. **分數變了，卡片上的等級要等下一次內容變動才更新**：為了不讓整頁快取失效，沒有替分數加快取失效條件
4. 正式站落日飛車底下有兩個系列：「My jinji 日版」（`/1`，使用者當初沒有版本欄，只好把日版寫進專輯名）與「My jinji」（`/2`，第 4 則掛這個）。使用者去編輯第 4 則選「日版」之後，`/1` 那個系列可以在後台合併掉，這次沒動
