## 5. 發文者編輯已發布的內容

- 單則頁發文者看得到「編輯」（在「編輯照片」旁邊），開 `/share/{n}/edit`，表單跟發文同一個元件，帶入原本的值；照片仍在單則頁「編輯照片」改。沒連系列的收藏，原本的「補上系列或品項」也改連到這頁
- 可改：說明、標籤、跟誰有關、系列＞品項＞版本（可選「不確定」）、出售狀態與價格。標題照第 4 項自動重組
- API `PUT /api/shares/{n}`：非發文者 403（管理員例外，只能改內容、不能改出售狀態，改別人的寫 `admin_log`「編輯別人的炫收藏」）、沒登入 401、鎖定中 423、被隱藏或刪除 404、已成交改出售狀態或價格 409「已成交，出售狀態與價格不能改」（內容仍可改）
- **出價中改價格**：沿用現有交易規則（跟賣家條同一支 `setSale`），允許改，並在這則的每條私訊對話插一行系統訊息通知出價者，例如「改為定價出售 NT$ 1,500」。沒選擋下，因為賣家條本來就能在有人出價時改價，兩個入口規則要一樣
- 出售狀態沒變就不送，海外會員改說明不會被「交易僅限台灣」擋
- 單則頁顯示「最後編輯於 2026/09/28 01:23」（台灣時間），存在新欄位 `shares.edited_at`；「編輯照片」存檔也會更新
- 整頁快取：`shares` 有內容版本觸發器，存檔後版本號前進，下一個請求就是新內容（驗收 5e、5f 存檔後立刻抓單則頁已是新標題與新說明）
- 改版本時：系列頁的版本區塊、排序、統計都是讀這則目前掛的版本即時算，舊版本不再列、新版本列出（5g）。發炫收藏的計分事件以收藏編號為準，改版本不會多一筆（5h、5i 重算後事件數不變）。頭號樂迷看的是作品頁有效編輯，跟收藏掛哪個版本無關
