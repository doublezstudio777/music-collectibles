2026-09-25，網頁設計顧問第二輪。上一輪方向 B 的色系作廢，排版邏輯保留。這一輪在「黑、白、橘」三色框內出兩套，視覺參考 Mercari，首頁改分頁。

示意頁：`方向A.html`（白牆市集）、`方向B.html`（暗房唱片行）。單檔各含首頁（分頁版）＋單則收藏頁 `/share/1`，頂端深灰那條是示意切換列，不是產品的一部分。示範資料抄自 `網站/lib/data.ts`，另外替 12 則收藏各指定一種出售狀態；封面全部是灰色塊，真實照片上線後會把顏色帶回來，這裡故意不放彩色塊，讓三色的比例看得清楚。截圖在 `img/`（每套首頁與單則頁各 1440 與 390，共 8 張），現況三頁在 `img/現況/`，Mercari 參考在 `img/參考/`。`_產生器.py` 是兩個 HTML 的來源，改資料或色票重跑即可。

沿用不動的規範（`網站/DESIGN.md`）：Inter → Noto Sans TC 無襯線骨架、IBM Plex Mono 只給目錄號與物件類型、字級五階固定 rem、全站直角零陰影、grid 用 `minmax(0,1fr)`、動效 150–250ms 加 `prefers-reduced-motion`。對比門檻：正文 ≥4.5:1、18pt（24px）以上或粗體 14pt（18.66px）以上 ≥3:1。下面所有數字都用 WCAG 公式算，不是目測。

## 跟蝦皮拉開距離

蝦皮橘是 `#EE4D2D`，偏紅；它的用法是**大面積**：整條導覽列、banner、折扣角標、白字壓橘的按鈕。白字壓蝦皮橘實算 3.66，本來就過不了正文門檻，所以蝦皮的橘永遠只能當背景。

音藏做相反的五件事：

1. **橘偏黃不偏紅**：`#FF6A00`／`#FF7A1A`，跟 `#EE4D2D` 擺在一起一眼就是兩個顏色
2. **橘的面積 <5%**：導覽列是白或黑，橘只在價格、主按鈕、當前分頁這三個點。蝦皮的橘是牆，音藏的橘是標籤
3. **永遠黑字壓橘，不用白字壓橘**：白字壓橘是全台電商的共同記憶（蝦皮、momo 的按鈕），黑字壓橘是工業標籤、安全背心、Discogs 的橘，第一眼就換了語境
4. **直角、零圓角、零漸層、零陰影**：蝦皮是圓角 + 漸層 banner + 陰影卡片
5. **沒有折扣百分比、沒有倒數、沒有免運標、沒有「熱銷」角標**：這些是零售語言，收藏交易不需要

其中第 2 與第 3 兩條就夠了；1、4、5 是保險。

## 推薦

**推 A。**

理由回到功能定案，不是品味。9/25 定案「外觀走電商」「首頁分頁」「買賣進來規劃」，這個站的入口是**商品牆**，使用者要在一格格照片之間比價格、比狀態。白底是商品牆的預設（Mercari、Yahoo 拍賣、Discogs 市集、eBay 全是白底），使用者拍的收藏照多半在白桌、白牆、木桌上，放在白底上是同一張紙，放在黑底上會變成一格格發光的矩形，磚框只能壓住一半。上一輪的深色方向 A 被否決過一次，這次 B 只是換了橘，深底的體質問題沒變。

A 的另一個優勢是價格膠囊壓在封面上：牆上掃一眼，哪些在賣、多少錢、哪些賣掉了，不用讀字。B 的價格在封面下面，跟標題混在一起，掃描速度慢一拍。

B 值得留的是**單則頁的交易區**：黑底上的橘字價格 32px，比 A 的深橘 `#B93E0A` 亮得多。如果之後想讓「我要買」那一屏更有戲，可以把 A 的單則頁交易區做成黑底小區塊（站中站的手法），其餘照 A。這不必現在決定。
