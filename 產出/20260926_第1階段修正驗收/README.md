## 已知問題與取捨

1. **撤回選擇「標記不移除」**：跟拒絕、成交一樣留紀錄，公開列表看得到「已撤回」灰字。若之後覺得
   列表太雜，可以改成完全移除，屬單純顯示決策，不影響資料層（`withdrawn` 狀態已存在，只是 UI 要不要畫出來）
2. **「去單則頁成交」是文字連結不是按鈕**：私訊裡賣家接受出價後，若想成交要點連結跳去單則頁，
   多一次頁面切換；這是刻意的（成交只留一條路），但體驗上比原本直接在私訊按鈕成交多一步
3. **改回出售中不會通知任何人**：目前只有賣家自己看得到狀態變回出售中，買家端只會在下次開啟私訊
   或單則頁時看到系統訊息「賣家改回出售中」，沒有主動通知（本階段沒有帳號與推播機制）
4. **個人頁「出售中」分頁沒有再細分定價／開放出價兩個子分頁**：兩種狀態混在同一個牆裡，跟商品卡本身
   的貼片區分開；如果之後量大，可能要加篩選
5. **驗收腳本只挑第 1 階段驗收清單裡跟這 5 項有關的頁面重跑**，沒有覆蓋首頁分頁、表單、藝人頁等
   這輪沒改動的頁面；那些頁面沿用上一輪（`產出/20260926_第1階段驗收/`）的驗收結果，本輪沒有回歸測試
