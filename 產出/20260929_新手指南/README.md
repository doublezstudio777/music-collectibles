## 做了什麼

### 1. 新手指南 `/guide`

- 正文照 v3 逐字，站名讀 `SITE_NAME`。最後加兩段：「開發中」寫「更多功能開發中」；「意見回饋」寫「問題與建議請填意見回饋表單」，連到 `/feedback`
- 錨點：`#share`、`#contribute`、`#trade`、`#report`、`#levels`、`#titles`、`#upcoming`、`#feedback`
- 圖放在 `網站/public/guide/`（英文檔名，只放 WebP 的 1x 與 2x）。等級階梯、得分方式用 `<picture>`，640px 以下換手機版；操作示意分別放在炫收藏、補資料、回報三段，特別稱號圖放在特別稱號段。alt 寫的是圖上的內容，等級與得分的 alt 也是從常數產生
- 入口：頁尾「新手指南」；自己的個人頁有「新手指南」按鈕，點了開對話框（手機從底部滑出，沿用回報對話框的樣式）；全站的等級標籤點了連到 `/guide#levels`
- 等級標籤原本包在「暱稱連結」裡面（收藏卡片、單則頁），連結不能包連結，所以搬到暱稱連結的後面，並補回原本 8px 的間距。標籤改用一般的 `<a>`：站內換頁到 `#levels` 時畫面不會捲到錨點，整頁載入才會
- `/guide`、`/ranking`、`/feedback` 都加進整頁快取白名單（`worker.ts` 的 `CACHEABLE`），正式站第二次請求都是 HIT

### 2. 意見回饋 `/feedback`

- 類型六選一、內容 2000 字以內、回覆用 Email（未登入必填，已登入預設帶自己的，可以改）、附件照片選填 1 張
- 照片在瀏覽器壓成 WebP（跟炫收藏同一支 `prepareImage`），存 R2 的 `f/`，只有管理員看得到（走 `/api/admin/feedback/photo`，不經過 `/img/`），容量照常計入 R2 總量
- 未登入也能送：一定要過 Turnstile，每個 IP 每小時 5 則
- 送出後只顯示「已收到」
- 後台新增「意見回饋」分頁：未處理、最近處理 50 筆；可以寫內部備註、標記已處理、改回未處理，每個動作寫操作紀錄；儀表板多一格「未處理的意見回饋」
- 隱私權政策的「其他申請：聯絡信箱待補」改成連到 `/feedback?type=privacy`；使用條款藝人照片段的「（聯絡信箱待補）」改成連到 `/feedback?type=takedown`。全站 grep 已經沒有「聯絡信箱待補」

### 3. 資料空白處的「補上」

| 位置 | 空白時顯示 | 點了 |
|---|---|---|
| 藝人頁沒有簡介 | 簡介待補 ＋「補上」 | 進簡介編輯（`?edit=1#intro`） |
| 系列頁沒有正文 | 正文待補 ＋「補上」 | 進正文編輯 |
| 系列頁發行年 | 發行年待補 ＋「補上」（原本是「我知道，補上」） | 就地出現輸入框 |
| 版本的發行年、地區、發行、包裝、內容物 | 各欄「○○待補」＋「補上」（原本是「待補」後面接欄位名稱） | 就地出現輸入框 |
| 版本沒有曲目 | 曲目待補 ＋「補上」（原本收在摺疊區塊裡的「補上曲目」連結） | 進曲目編輯 |
| 辨識細節的目錄號、辨識特徵（登入才看得到） | 同版本欄位 | 同上 |

未登入點了，先開登入面板；面板就在原頁上，登入完直接接著進編輯。輸入框的送出鈕從「補上」改成「儲存」，避免同一排出現兩個「補上」。

### 4. 收藏榮譽榜 `/ranking`

- 本月貢獻榜（本月入帳分數前 20）、總榜（累計分數前 20）、打假先鋒（全部）、頭號樂迷（每位藝人一位，依藝人名稱排序）
- 資料在每日計分排程裡整張重算，寫進 `rankings` 表，頁面只讀這張表。「本月」用台灣時間的月份比對入帳時間，所以 1 日凌晨那次排程就自然換成新月份
- 館長（`ADMIN_EMAILS`）、停權與已刪除的帳號不列
- 每列只有名次、大頭貼、暱稱、等級、分數；上榜不到 5 人的榜整張不顯示
- 入口：頁尾、頭像選單；個人頁在有上榜而且本月榜有顯示時，出現「本月第 N 名」
- 正式站 `rankings` 目前是空的（排程還沒跑過新版本），頁面顯示「目前沒有榜單」。今晚 02:00（台灣時間）排程跑完就會有資料

### 5. 新增 +15 當下入帳

- 會員新增藝人、系列、版本時，當下寫一筆「已入帳」的事件，並直接加進 `user_scores`，不等每日排程
- 新增藝人以前不給分，這次加上（事件來源用 `catalog_additions` 的 id，管理員改藝人識別碼也不會重複給分；改識別碼時順便把 `catalog_additions.ref` 一起改）
- 被合併或刪除，下一次每日彙總作廢扣回（跟原本新增系列、版本的規則同一套）
- 計分表都沒有內容版本觸發器，不會讓整頁快取失效

## 判斷項（請使用者看）

1. **新增藝人開始給 +15**：v3 寫「新增藝人、專輯、版本 +15」，原本程式只給系列、品項、版本，這次把藝人補上。品項（例如同一個系列多一個「黑膠」品項）照舊也給 +15，這條 v3 表格裡沒寫
2. **「補上」旁的欄位字樣**：用「○○待補」（例如「地區待補」），沿用原本「發行年待補」的寫法，沒有另外加提示句
3. **系列頁沒有正文時寫「正文待補」**：編輯器對這一欄的名稱是「正文」，所以沿用；如果想叫「簡介」要改一個字
4. **意見回饋那一行的文字**：「問題與建議請填意見回饋表單」。你指定的是「寫一行，連到表單」，字是我擬的
5. **本月榜的「分數」欄顯示本月入帳的分數**，其他三張榜顯示累計分數
