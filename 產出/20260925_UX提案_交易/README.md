## 交易模式的前提

- 每則炫收藏帶一個「出售狀態」：**純分享**（預設）、**開放出價**、**定價出售**，賣家隨時可改。
- 這一輪做到**成交前**：問價、談、賣家標「已售出」。付款、寄送、評價、抽成都不在這輪。
- 成交是賣家手動按的，站上沒有金流可以自動判定。

Mercari 觀察到的事實（9/25 用 Playwright 看 jp.mercari.com，台灣 IP 會被擋出品頁，只看得到搜尋與商品頁）：

| 看什麼 | Mercari 的做法 |
|---|---|
| 搜尋結果牆 | 1440 寬五欄，正方形圖，價格是貼在圖左下角的深底圓角貼片，圖下兩行標題，卡上沒有賣家 |
| 已售出 | 圖左上角紅色三角「SOLD」，商品照常留在結果裡；篩選有「只看販售中」開關 |
| 商品頁 | 左圖（縮圖直列＋大圖）右資訊：標題、價格、讚數、一顆整寬紅色「購入手続きへ」、描述、商品資訊表（分類、狀態、寄出地）、賣家卡（評價數、本人確認）、底下推薦同類商品 |
| 分頁 | 搜尋結果底部只有「次へ」，沒有頁碼 |
| 出價 | 2024 年起有「希望価格の登録」：買家登記想買的價格，賣家看到「有 N 人想用 ¥X 買」，可以降價回應；早期的「オファー」功能是一對一出價，24 小時未回自動取消 |
| 出品欄位（依官方指南） | 照片、商品名（40 字內）、說明、分類、商品狀態六級、運費由誰出、寄送方式、價格 |

拿來用的只有三件：價格貼在圖左下角、已售出照留在牆上、篩選「只看出售中」。其餘（商品狀態六級、運費、寄送方式）屬付款寄送層，這輪不做。

## a. 表單：出售狀態欄的位置與預設

線框 `#new`。

- 三格必填照舊：照片、這是什麼東西、跟誰有關。順序不動。
- 「出售狀態」放在**最後一格**，在「其他標籤」之後、「發布」之前。欄名「要不要賣」，三段切換：`純分享｜開放出價｜定價出售`，預設停在「純分享」。
- 選「定價出售」時，切換列底下多出一格 `NT$ ____`，必填整數。選另外兩個，這格不出現。
- 「開放出價」沒有任何附加欄位。
- 不放在必填三格前面的理由：這個站的入口動作是炫收藏，賣是附帶的。欄位放在最後，填純分享的人（預設大多數）看到它時已經填完，直接按發布；放前面會讓表單第一眼像 Mercari 的出品頁。
- 沒有「含運／不含運」「面交或寄送」「商品狀態」欄。這些在私訊裡談，等付款寄送那輪再決定要不要結構化。

| 純分享 | 沒有貼片 | 跟前一輪一模一樣 |
| 開放出價 | 白底黑框貼片「開放出價」 | |
| 定價出售 | 黑底白字貼片「NT$ 1,200」 | |

| 已售出 | 灰字「已售出」＋劃線價格「~~NT$ 500~~」＋成交日；沒有按鈕。開放出價成交的則沒有價格，只有「已售出」＋日期 |

照片左下角的貼片跟牆卡同一套。

### 賣家自己看單則頁（`#s5`）

標題上方一條淺灰底的操作列：三段切換 `純分享｜開放出價｜定價出售`、價格框（只在定價出售時出現）、「標為已售出」按鈕。切換立即生效，不另開編輯頁。

出售區塊對賣家顯示的是「NT$ 350 · 2 人問過 · 看私訊」，沒有買的按鈕。

「標為已售出」按下去彈一個小面板：這則有進行中私訊時，列出這幾位讓賣家選成交給誰（可以不選，直接標）；沒有私訊就直接標。已售出後操作列剩「已售出 · 9 月 20 日」＋「改回出售中」。

## c. 問價與購買動線

### 私訊要不要獨立頁：要

理由三條。一是同一個人可能同時問三件東西、或被五個人問同一件，需要一張總表；二是賣家「可以不理」這件事要在介面上成立，未讀訊息就得有一個不打擾的存放處，不能彈在單則頁上；三是私訊的內容（面交地點、匯款）不該出現在任何公開頁。

網址：`/messages`（清單）、`/messages/{對話id}`（單一對話）。桌機兩欄（左清單 320px、右對話），手機兩頁。導覽列在「炫收藏」按鈕左邊多一個信封圖示，有未讀時右上角一個黑點，沒有數字。

私訊的規則：

- **只能從一則炫收藏發起**，沒有「私訊這個人」的入口。對話永遠掛在一則收藏底下，對話頂端固定顯示那則的縮圖、標題、目前狀態，點了回到那則。
- 同一個買家對同一則只有一條對話，重複按「出價問賣家」回到同一條。
- 賣家對同一則有幾個買家就有幾條對話，清單裡看得到各自最後一句。
- 沒有已讀標記、沒有「賣家通常在 N 小時內回覆」、沒有催促。賣家不理就是不理。
- 對話裡的「出價」「我要買」是結構化訊息（框起來、金額大字），不是純文字，之後標已售出時系統才抓得到金額。

### 動線一：開放出價（`#s2` → `#msg` → `#msg2` → `#s4`）

1. 買家在 `#s2` 按「出價問賣家」。未登入彈前一輪那個登入小面板，登入後留在原頁。
2. 進 `/messages/{id}`，對話頂端釘著這則。輸入列左邊多一顆「出價」按鈕，按了出現金額框，送出後在對話裡是一個框起來的「出價 NT$ 800」；也可以不出價只打字問。
3. 賣家的信封亮黑點。賣家開 `#msg2`，看到「阿哲 · 海港音樂祭 2019 演出海報 · 出價 NT$ 800」。三種反應：回訊息、不理、或按對話頂端的「成交給這位」。
4. 賣家按「成交給阿哲」→ 這則變已售出，這條對話插一行系統訊息「已成交 NT$ 800」；同一則的其他對話各插一行「這件已售出」。
5. 買家回到 `#s4`，出售區塊是「已售出 · 9 月 20 日」，牆卡貼片變「已售出」。

賣家也可以不透過私訊，直接在 `#s5` 按「標為已售出」，面板會列出問過的人讓他選，選了效果同第 4 步。

### 動線二：定價出售（`#s3` → `#msg2` → `#s4`）

1. 買家在 `#s3` 按「我要買」。未登入同上。
2. 進對話，系統代買家送出一個框起來的「我要買 NT$ 350」，買家接著打字（面交或寄送、什麼時候）。按「問賣家」則是進同一條對話但不送那個框。
3. 之後跟動線一第 3 到 5 步相同。賣家按「成交給小孟」時金額就是定價。

兩條動線只差第 2 步的那個框，介面元件全部共用。

### 賣家改狀態對進行中對話的影響

| 賣家動作 | 進行中對話 |
|---|---|
| 定價出售改價格 | 每條對話插一行「價格改為 NT$ 300」 |
| 改成純分享 | 每條插「這件不賣了」，對話保留可以繼續講 |
| 改成開放出價 | 每條插「改為開放出價」 |
| 標已售出 | 成交那條插「已成交」，其他插「這件已售出」 |
| 已售出改回出售中 | 每條插「重新開放」 |

系統訊息一律灰色小圓角，置中，跟人講的話分開。

## d. 單則頁底部：同藝人／標籤／作品的其他收藏

用戶定案：不放「這位會員的其他收藏」，改放跟同一個主題有關的。

規則：

1. 最多兩個區塊，每塊三張卡＋「全部 N 則」連到標籤頁或作品頁。
2. 區塊來源依序取：「跟誰有關」的**藝人標籤**（照填寫順序）→ **連到的作品**（有連才算）→ 其他標籤。取到兩個就停。
3. 標題格式：作品用「夜行採集的其他收藏」，藝人或標籤用「跟山線電台有關的其他收藏」。
4. 後一塊排除前一塊已經出現的則；來源不足三則的區塊整塊不出現，不補其他來源湊數。
5. 分享者本人的其他則不排除，但也不優先；它們跟別人的一樣照時間排。

線框對照：`#s1`（有連作品：第一塊藝人、第二塊作品，因為這則的「跟誰有關」只有一個）、`#s2`（沒連作品，兩個藝人標籤：山線電台、海港音樂祭）、`#s4`（有連作品且只有一個藝人標籤：第一塊作品、第二塊藝人）。

規則 2 把藝人排在作品前面的理由：「跟誰有關」是必填、作品是選填，多數則只會有藝人；讓第一塊永遠是藝人，讀者在不同則之間切換時第一塊的形狀固定。另一種排法是有連作品時作品優先，兩種都畫得出來，寫進需回問 4。

## e. 首頁改分頁

線框 `#home`。

- **每頁 24 則**。1440 三欄八列，390 兩欄十二列。理由：三欄與兩欄都整除，翻一頁的長度在手機上約四個螢幕高，不會像無限捲那樣讀不到底。
- **頁碼在牆底部置中**：`‹ 上一頁  1  [2]  3  4  5  …  12  下一頁 ›`。目前頁黑底白字，每個目標 44px。手機收成 `‹  2 / 12  ›`。網址 `/?page=2`，可以分享、可以回上一頁。
- **不分區塊，用篩選**。牆上方一排三個 chip：`全部｜定價出售｜開放出價`，預設全部，右邊照舊一個排序下拉（最新／最多讚）。不做「最新／定價出售中／開放出價」三個區塊的理由：純分享是預設，開站前幾個月出售中的則會很少，切成三塊有兩塊是空的或只有兩張卡；篩選讓牆永遠是一面完整的牆，出售中的則靠貼片就看得出來。Mercari 也是用「只看販售中」開關而不是分區。
- 篩選與頁碼組合：`/?state=sale&page=2`，切換篩選回到第 1 頁。
- **已售出的則留在「全部」裡**，照時間排；「定價出售」「開放出價」兩個篩選不含已售出。
- 手機牆從一欄改兩欄。前一輪是一欄，這輪改的原因是分頁：一欄 24 則約 11,000px，兩欄約 4,000px。Mercari 手機也是兩欄。兩欄時標籤列收掉，標題兩行、字級 14。這是版型變動，寫進需回問 5。

## g. 需回問用戶

1. **交易模式本身**。主對話建議的三狀態（純分享預設／開放出價／定價出售，賣家隨時改，只做到成交前）本稿全照這個推，用戶尚未回覆。若要改成別的（例如只有「賣／不賣」兩態、或定價必填），表單那一格與貼片跟著改，其他動線不受影響。
2. **出價要不要公開**。本稿出價走私訊，只有雙方看得到。Mercari 現在的「希望價格」是公開的（「有 3 人想用 NT$800 買」），這會給賣家壓力也會給其他買家參考。要私下還是公開？
3. **「我要買」在沒有金流時等於進私訊**，按鈕文字仍寫「我要買」。要不要改成「私訊購買」之類的？本稿留「我要買」，因為之後接金流時不用改字。
4. **單則頁底部第一塊放藝人還是放連到的作品**。本稿第一塊固定藝人（因為必填）、作品第二塊；另一種是有連作品時作品排第一。
5. **手機牆改兩欄**。前一輪一欄、這輪因分頁改兩欄。要保留一欄的話，每頁 24 則在手機會很長，建議降到 12。
6. **已售出的則要不要留在首頁「全部」裡**。本稿留（Mercari 留）。另一種是已售出只在個人頁看得到。
7. **私訊要不要寄 Email 通知**。第一階段只有 Email 帳號，賣家不常上站的話會錯過出價。本稿沒畫通知，若要，建議只在「有新對話」時寄一封，同一對話後續訊息不寄。
8. **賣家能不能「拒絕」一個出價**。本稿賣家只有回、不理、成交三種，沒有「拒絕」按鈕，因為拒絕按鈕會讓「不理」變成一種失禮。要不要加？
