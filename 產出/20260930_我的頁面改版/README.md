## 做了什麼

1. 選單與 `/me` 標題「我的頁」改「我的頁面」
2. 自我介紹：設定頁暱稱下方，200 字，保留換行（個人頁 `white-space: pre-line`）。整理規則沿用留言（控制字元、連續空行壓成兩行），站外交易字眼（網址、LINE、@帳號、匯款…）直接擋，因為個人頁沒有「小心站外交易」提醒可掛，社群連結另有欄位
3. 社群連結：IG、Threads、YouTube、Facebook 四欄，伺服器驗網域白名單（含子網域）、只收 https、不收帳密與連接埠、要有路徑；沒寫 https:// 自動補。個人頁單色線條圖示，`target=_blank rel="noopener nofollow ugc"`
4. 最喜歡的藝人：只能選前台看得到藝人頁的，最多 5 位，↑↓排序、移除；個人頁小標籤連藝人頁，隱藏或刪除的不顯示（伺服器存時也擋）
5. 個人頁本人才有「編輯個人資料」（連 /settings，取代原本的「設定」鈕；設定仍在頭像選單）
6. 大頭貼裁切視窗：自己寫，**沒加套件**。Pointer Events 同時處理滑鼠與觸控，雙指縮放、滾輪、滑桿、鍵盤方向鍵；預覽畫在取景框大小的 canvas，來源縮到長邊 2048 的工作圖，確定時從原圖取正方形輸出 256×256 WebP；原圖不上傳
7. （追加）收藏卡片與單則頁作者欄改用 `Ava`：有大頭貼顯示大頭貼。目錄帶 `authorAvatar`，換大頭貼寫 users 觸發內容版本，整頁快取跟著換新（本機驗過換圖後首頁卡片立刻換成新圖）。全站其他顯示會員的地方（留言、出價、榮譽榜、系列頁貢獻者、個人頁）原本就用 `Ava`；私訊列表顯示的是收藏縮圖不是頭像，沒動
8. （追加）首頁標語換定稿，訪客與登入都顯示：收合第一句＋「看更多」原地展開，「來信告訴我們」連 /feedback；關於頁全文放在站長四段前面。撤掉 f7dedea 的登入者收起（`<html data-auth>`、`lmb_auth`、`suppressHydrationWarning`），layout.tsx、account.tsx 回到修之前
9. （追加）會員照片授權改 CC BY-NC-ND 4.0：投稿勾選文字、使用條款、頁尾版權列＋官方 88×31 標章（站內檔 `public/brand/cc-by-nc-nd-88x31.png`）。維基照片出處沒動。正式站會員投稿的藝人照片 **0 張**（48 張全是維基），沒有舊 BY-SA 會員照片要處理
