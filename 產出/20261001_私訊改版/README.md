# 私訊改版＋頁首願望清單（2026-10-01）

正式站 Cloudflare Version ID `58d6612e`，遷移 `0026_dm`（接在 autofill 的 `0025` 後面）。規格是使用者核准的版本，逐項對照在下面。

## 改了什麼

| 規格 | 做法 |
|---|---|
| 頁首私訊 | 信封換成直角對話框線條圖示，文字「私訊」。全站沒有「聊聊」 |
| 頁首願望清單 | 愛心（跟點讚同一顆），連 `/me/likes`。頁面標題、選單、個人頁按鈕、未登入提示、隱私權政策那句「喜愛清單」全部改成「願望清單」 |
| 未讀 | 橘底黑字小方塊＋數字（有未讀的對話數，99+ 封頂），不用紅點。換頁或切回分頁時重讀（最多 15 秒一次，不輪詢） |
| 桌機／手機 | 桌機圖示旁有文字；700 以下只放圖示，每個連結都有 aria-label（「私訊，3 個對話未讀」） |
| 私訊列表 | 收藏相關與直接私訊同一個列表，依最新一則訊息排序；收藏相關顯示縮圖＋標題，直接私訊顯示對方大頭貼；未讀整列加粗＋數字方塊 |
| 收藏頁入口 | 定價出售、開放出價：「問賣家」（開放出價原本沒有，這次補上）；純分享、已售出、交易暫停：「私訊」。對話釘住那則 |
| 不同收藏不同對話 | 原本就是（一位買家對一則一條），保留 |
| 個人頁入口 | 「傳訊息」開直接私訊，一對人只有一條 |
| 自己的不顯示 | 自己的收藏、自己的個人頁都沒有這些按鈕 |
| 驗證 Email | 開對話、傳文字都要驗證過；沒驗證的按鈕下方寫「驗證 Email 後才能私訊」＋「驗證 Email」 |
| 每日上限 | 每人每天（台灣日期）主動開 10 個新對話；「開」＝發起人在還沒開始的對話送出第一則（文字、出價、我要買都算）。已經在聊的不限。後台「私訊檢舉」頁可調（settings `dm_daily_new_limit`） |
| 封鎖 | 對話右上「封鎖」→確認。任一方封鎖後兩人都不能再傳、不能開新對話、也不能對彼此的收藏出價；封鎖的人要先解除。設定頁「封鎖名單」可解除 |
| 檢舉 | 對話右上「檢舉」：騷擾／詐騙／廣告洗版／其他＋補充，一條對話一次。進後台 `/admin/dm-reports` |
| 後台不顯示內容 | 後台只列時間、誰檢舉誰（被檢舉累計次數）、理由、補充、收藏 #n 或直接私訊。會員頁的對話數改成含直接私訊 |
