# 首頁上方設計圖（2026-09-29）

只出設計圖，網站程式沒動、沒部署。HTML 直接用瀏覽器開（`site.css` 是正式站 9/29 的樣式表原檔，`mock.css` 是新加的部分），「換一首」可以按，會在落日飛車、MC HotDog、國蛋三首之間輪。

三案共通：
- 頁首加「藝人」：桌機在搜尋框右邊，手機搜尋框收成圖示後落在站名右邊
- 歌曲卡是 Spotify 官方嵌入播放器（152px 高），封面、歌名只出現在播放器裡；站上只寫藝人名、分類、收藏數、「看 XX 的收藏」、「換一首」
- 原本的「熱門藝人」清單（國蛋／落日飛車／MC HotDog＋追蹤＋不感興趣）拿掉，位置讓給歌曲卡。要不要保留待使用者決定
- 收藏牆、追蹤中／最新／最多讚、只看在賣照舊

## A 單曲橫條
- 特色：標語下一條黑線，左邊播放器、右邊藝人名與按鈕；藝人入口只有頁首「藝人」加一個「全部藝人」小連結
- 優點：最省高度，跟現在白牆調性最接近，改動最小
- 代價：藝人入口仍偏弱，只比現況多一個頁首連結；手機上歌曲區約佔 330px

## B 歌＋藝人兩欄
- 特色：左 2/3 歌曲卡，右 1/3「藝人」清單（男歌手 17／女歌手 4／團體 4／全部藝人 25），用分類當入口，不列出個別藝人
- 優點：藝人入口最明顯，桌機首屏左右都有東西，上方不空；手機分類收成一條可橫滑的列
- 代價：高度最多，桌機收藏牆往下推約 60px；分類連結要 `/artists` 支援 `?type=` 篩選（現在頁面上有分類按鈕，但網址參數要確認）

## C 黑色播放帶
- 特色：頁首下整條黑底，藝人名 40px 大字＋暗色播放器＋右側藝人分類，標語收進黑帶底部
- 優點：音樂感最強，一眼就知道這是音樂網站；手機上反而最省（標語在手機隱藏）
- 代價：違反目前「白牆」調性，黑底面積大；手機拿掉了標語；黑帶會蓋過下面收藏照片的存在感

## 推薦
B。使用者兩個問題（上方太空、看全部藝人不明顯）B 都正面回答，而且沒離開既有黑白橘直角的系統。C 視覺最有記憶點但要改調性，建議當 B 上線後的備案。

## 注意事項
- Spotify 播放器的圓角、底色（依封面取色）、「Preview」字樣都是 Spotify 畫的，改不了；全站直角只有這一塊例外
- 手機上播放器的藝人名會被截斷（Spotify 自己的排版）
- 歌曲清單正式實作時要有資料來源：Spotify 曲目 ID 可從 MusicBrainz 的專輯連結取得，再用 `open.spotify.com/embed/album/{id}` 讀曲目；本次用到的 ID：
  - 落日飛車 My Jinji `0JTkPVNmfsy86OWvlXrtIW`
  - MC HotDog 我愛台妹 `3vTuu6YNTEOby4HK7bWhB2`
  - 國蛋 SOUR `3kwZakaIDOMYkBDmIFV1T7`
- 播放器第一次載入約 1 到 2 秒，實作時先放同尺寸灰框佔位避免版面跳動

## 設計學習（樂迷藏專屬）
- 使用者說「上面很空」指的是版面結構，不是內容量；用有互動的音樂元件（播放器）填首屏比加標語或清單有效
- 藝人入口不列個別藝人，改用分類＋總數當入口，避開「藝人太多排版醜」
