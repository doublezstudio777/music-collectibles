# 正式網域前，品牌名稱再評估

日期：2026-09-30。來源：本輪與使用者討論。

## 問題與目前結論

使用者希望網站使用正式網域、開始放自己的收藏並對外上線；表示網域尚未購買，想到 `lemibox.com`，隨後說品牌名稱尚未確定，希望先取得新建議。比較後，使用者決定沿用「樂迷藏」，理由是「可以讀樂迷，也可讀迷藏」。**品牌定案，網域未定，也未購買或切換。**

網站目前已使用「樂迷藏」，且部分使用者照片已燒入這個名稱的浮水印。改品牌將有 UI、法務文字、信件、浮水印重燒等成本；只改網域則不用改照片。命名需容納唱片、場刊、周邊、版本資料、樂迷分享與站外撮合，不能只像串流服務或唱片店。

## 初步候選與取捨

| 名稱 | 合適之處 | 顧慮 |
|---|---|---|
| 樂迷藏 | 明確指向樂迷及收藏，既有使用者認得，改動成本最低 | 「藏」可能先讓人想到私人收藏，需用首頁文案說清楚可看別人的收藏與分享自己的物件 |
| 樂物所 | 重點在音樂相關實體物件，唱片、場刊和周邊都可收 | 「樂」讀音不唯一；聽起來可能像商店，樂迷社群感較弱 |
| 樂物誌 | 有編目和紀錄感，適合版本資料 | 偏雜誌／編輯內容，使用者分享與交易意圖不直觀 |

### 第二輪（使用者追問「還有其他更好的嗎？」）

重新以「樂迷分享實體收藏」為主軸，較有競爭力的新候選是 **樂物集**：樂＝音樂，物＝唱片、場刊與周邊，集＝收藏的集合，也有樂迷聚在一起之意。比「樂物所」少一點商店／店面感，比「樂物誌」更能容納會員投稿。其缺點是第一次看到「樂」仍可能讀成快樂的樂，需要搭配一句清楚的產品說明。初步網路精確搜尋未見明確同名服務，但這不能替代商標、公司名稱、社群帳號與網域查核。

其他試過的方向：「樂迷集」強調社群但沒說物件；「樂物圈」有社群感但較像論壇；「樂有所藏」有句子感但太長且不易作網址；因此不列入最後兩名。

**決策結果**：使用者選樂迷藏。樂物集、樂物所、樂物誌是討論過但未採用的候選，理由是原名的「樂迷／迷藏」雙讀更有記憶點。這是產品命名決策，商標仍需正式查核。

`lemibox.com` 可作網域候選，但「LemiBox」作英文品牌已有其他產品使用的搜尋結果；網域和中文品牌不必一對一。2026-09-30 查 Verisign .com RDAP 對 `lemibox.com` 回傳 HTTP 404，代表當下查無註冊紀錄，**不等於購買保證**，需在註冊商付款前重新查詢。

## 尚待決定

1. 選正式網域。`lemicang.com`、`yuemicang.com`、`lemibox.com` 在 2026-09-30 查 Verisign .com RDAP 均回 HTTP 404（查無當下註冊資料）；註冊商購買時仍需重新確認。
2. 正式使用前查經濟部智慧財產局商標檢索與近似名稱，必要時請專業人士確認；一般搜尋不能當作商標可用結論。
3. 網域選定後盤點 Cloudflare custom domain、Turnstile hostname、公開收錄、備份與法務頁的上線步驟。
